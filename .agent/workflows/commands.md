Denne workflowen beskriver trygge, standard bygg/test/git-kommandoer.

// turbo

1. Sjekk kode
   `cargo check`

// turbo
2. Kjor tester
   `cargo test`

// turbo
3. Bygg prosjektet
   `cargo build`

// turbo
4. Format-sjekk
   `cargo fmt -- --check`

// turbo
5. Clippy-sjekk
   `cargo clippy`

// turbo
6. Sjekk git status
   `git status`

// turbo
7. Stage alle endringer
   `git add .`
