# Agent Repo Index

Kort indeks for agenter og mennesker. `AGENTS.md` er startpunktet; `.agent/` er den dypere kilden for regler, veiledning og domene.

## Start Her

1. Les normative regler i `.agent/rules/repo_rules.md`.
2. Les praktisk veiledning i `.agent/guides/`.
3. Les domene- og arkivkunnskap i `.agent/skills/arkivfag/`.
4. Bruk `.agent/assets/diagram_text/` nar SVG-diagrammer er vanskelige a lese i CLI.

## Struktur

- `.agent/rules/`
  - _Normative repo-regler for agenter og kodeendringer._
- `.agent/guides/`
  - _Praktisk teknisk veiledning for kommandoer, observability og arkitektur._
- `.agent/skills/arkivfag/`
  - _Kanonisk arkivfaglig domenekunnskap. Denne mappen er hovedkilden for archive-domain rules._
- `.agent/skills/skuffen_architecture/`
  - _Tynn skill-peker til arkitekturveiledningen i `.agent/guides/architecture/`._
- `.agent/assets/`
  - _Tolkninger og beskrivelser av diagrammer._
- `.agent/manifest.yaml`
  - _Maskinvennlig indeks over regler, guides og kunnskapskilder._

## Bruksnotat

- Norske svar med English technical terms.
- Regler i `.agent/rules/` er normative.
- Guidance i `.agent/guides/` forklarer hvordan repoet fungerer.
- Innholdet i `.agent/skills/arkivfag/` skal behandles som kanonisk domenegrunnlag.
