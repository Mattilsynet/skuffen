# Agent Repo Index

Kort inngangspunkt for agenter og mennesker. Bruk denne for a finne regler, domene og kjorepraksis.

## Start her

1. Les kjerne-regler i `.agent/rules/`.
2. Sjekk governance i `.agent/governance/`.
3. Bruk domene/arkitektur i `.agent/skills/`.
4. Kjor vanlige kommandoer via `.agent/workflows/commands.md`.

## Struktur

- `.agent/rules/`
  - _Alltid-gjeldende regler og sprakkonvensjoner._
- `.agent/governance/`
  - _Plan, roadmap, risk og tasks (levende styring)._
- `.agent/skills/`
  - _Domene- og arkitekturressurser per skill._
- `.agent/workflows/`
  - _Kjorekommandoer og standard flyter._
- `.agent/assets/`
  - _Tolkninger og beskrivelser av diagrammer._

## Bruksnotat

- Norske svar med English technical terms.
- Regler i `.agent/rules/` er normative; skill-resurser er kunnskap.
