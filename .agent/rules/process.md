# Skuffen Prosess-regler

Normative regler for hvordan arbeid skal planlegges og gjennomføres i Skuffen.

## Oppgavehåndtering (Task Management)
- **Oversikt og kontroll:** Dokumentasjon skal speile virkeligheten.
- **Kilde:** Arbeid kan starte fra chat eller backlog, men `.agent/governance/tasks.md` skal oppdateres.
- **Seriell utførelse:** En oppgave av gangen. Fullfør eller dokumenter status før fokus byttes.

## Risikostyring (Risk Management)
- **Konsultasjon:** Les og forstå `.agent/governance/risk.md` for endringer som påvirker arkitektur/sikkerhet.
- **Dynamiske oppdateringer:** Endringer i `.agent/governance/plan.md` eller `.agent/governance/roadmap.md` krever oppdatert risikoanalyse.

## Planlegging
- Hold `.agent/governance/plan.md` effektiv og oppdatert.
- Hold `.agent/governance/roadmap.md` justert med langsiktig visjon.
