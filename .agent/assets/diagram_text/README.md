# Diagram-tekst

Denne mappen inneholder tekstlige tolkninger av SVG-diagrammer i `.agent/skills/.../resources`.
Bruk disse nar SVG ikke kan rendres, eller for rask lesing i CLI.

Regler:
- Hvert SVG har en tilsvarende `.md` med samme basename.
- Teksten er kort, presis og uten antakelser.
- Referer til original SVG der det er relevant.
